How to read these numbers

This is a keyword screen, not expert coding. Each college has five phases named for its own work, such as Assess, Interpret, Plan, Intervene and Communicate for Nursing. A phase is flagged when a summary contains its keywords, and it counts only if it rests on its own distinct passage. The counts show where to look. They can over- and under-count.

Colleges are not scored on the same yardstick. Because each college uses its own keywords, compare pattern strength across colleges with care. Phases and sequences can only be shown for one college at a time.

Rows are used as exported. Repeated rows in the source file are counted each time they appear. Six rows with no summary text are left out.

Complexity is not rated. The pep-analyzer rules require judging each phase from the student's own words, which a screen at this scale cannot do.

Revelation is a keyword match (God, prayer, Spirit and similar words) in the "Inspiring Learning" comments. Read each one in context before treating it as revelation.

Only counts are published here. No student comments, names or IDs are in this page.
