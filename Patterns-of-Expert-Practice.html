How to read these numbers

Every survey response was read. A phase counts only when a direct quote supports it. All figures are exact counts.

Who read them. Claude, an AI model, using the pep-analyzer rules. A faculty coder should check a sample before formal use.

Phases are named for each college's work, so they can only be shown one college at a time.

Revelation is a keyword match (God, prayer, Spirit) in the "Inspiring Learning" comments, not part of the reading.

Rows are used as exported. No student comments, names or IDs are on this page.
